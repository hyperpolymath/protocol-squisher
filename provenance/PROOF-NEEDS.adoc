Statements changed on 2026-11-18, because the old ones were false or did not
type-check:

* `wheelbarrow-needs-fallback` claimed every Wheelbarrow pair narrows or
changes signedness. String → Bool and Bool → F32 are counterexamples. It now
states that a Wheelbarrow pair is neither identical nor a safe widening.
* `compilation-implies-transport` claimed an adapter exists between any two
schemas. That fails for an empty target schema. It now takes a
validity-preserving map as a hypothesis.
* `class-correct` (in `SynthesizedAdapter`) quantified over every field. It
is now stated for fields in the list (`f ∈F fields`) and proved by induction.
* `concorde-safe` claimed every function `Set → Set` is lossless. It now
states that the identity conversion Concorde uses is lossless.
* `transitive-transport` dropped an ill-sorted `Set`-valued component.
It still returns the a → c strategy.

What remains weak: several statements in `CarriesInvariant.agda` and
`AdapterSynthesis.agda` (`concorde-always-succeeds`,
`protocol-squisher-invariant`, `synthesis-total`,
`synthesis-preserves-carries`, `synthesis-end-to-end`) only assert that a
strategy or a placeholder adapter exists. They do not relate it to real data.
In particular PQ4 does not prove field preservation: the synthesized
adapter is the same unit identity adapter for every field list.
`wheelbarrow-needs-fallback` proves only that a Wheelbarrow pair is neither
identical nor a safe widening; it does not show that a direct cast is lossy.

No CI job or recipe checks these files.

*Agda* for optimization soundness (existing). *Coq* for container
propagation (existing). *Idris2* for ABI extensions. The 758
`+unwrap()+` calls are a major safety debt that formal error handling
types would address.

=== Priority

*HIGH* — Protocol squisher handles serialization format translation.
Incorrect translation silently produces wrong data. The existing proof
infrastructure (Agda + Coq) demonstrates proof feasibility. The 758
unwrap() calls are the largest safety debt in this scan.
